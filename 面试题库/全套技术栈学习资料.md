## 1. Java 基础

类比：你把做菜的步骤写下来（代码），交给任何一个人（电脑），他都能按步骤做出菜来。

## 2. Maven

### 🔰 零基础定义
Maven 是 Java 项目的"管家工具"，帮你做三件事：
1. **管理依赖**：你需要用什么第三方的包（比如连接MySQL的驱动），告诉 Maven，它自动下载
2. **打包**：把项目打包成可运行的 `.jar` 文件
3. **标准化项目结构**：规定好代码该放哪个文件夹

类比：你装修房子（写项目），Maven 就是建材超市——你说要什么材料（依赖），它帮你买好送到家。

### 📌 本项目中的用法
- 在 `pom.xml` 中配置了所有依赖（Spring Boot、MyBatis、Redis 等）
- 用 Maven 命令启动项目、打包部署
- 核心配置文件 [pom.xml](pom.xml)

### 📚 极简学习教程

#### 2.1 项目结构（Maven 标准）
```
项目名/
├── pom.xml              ← Maven 配置文件（核心）
├── src/
│   ├── main/
│   │   ├── java/        ← Java 源码
│   │   └── resources/   ← 配置文件（.yml, .xml）
│   └── test/            ← 测试代码
```

## 3. MySQL + SQL

### 🔰 零基础定义
MySQL 是**数据库软件**，用来存数据。SQL 是操作数据库的"语言"。

类比：MySQL 就像一个有表格的 Excel 文件，SQL 就是你对 Excel 说的话——"查一下第3行"（SELECT）、"删掉第5行"（DELETE）。

本项目有 **5个** MySQL 数据库，管理着用户、设备、水质监测等所有数据。

### 📌 本项目中的用法
- 用户登录信息、设备数据、水质监测数据全部存在 MySQL
- 通过 MyBatis-Plus 操作数据库（写了SQL，但大部分自动生成）
- 5个数据库：gcdd（主业务）、jcxx（基础信息）、yjxx（预警）、collector（采集器）、eb_database（水资源）

### 📚 极简学习教程

#### 3.1 必须掌握的 SQL（本项目常用的）
```sql

SELECT id, name FROM user WHERE age > 18;        -- 条件查询

-- ② 新增（INSERT）
```

## 6. MyBatis / MyBatis-Plus

### 🔰 零基础定义
MyBatis 是**操作数据库的工具**。不用它的话，你要写很多重复代码去连接数据库、执行 SQL、处理结果。MyBatis 帮你省掉这些"苦力活"。

**MyBatis-Plus** 是 MyBatis 的增强版——连 SQL 都不用写，自动帮你生成增删改查。

类比：
- MyBatis = 你告诉它"去数据库查用户"，你写SQL，它帮你执行
- MyBatis-Plus = 你都不用说话（不用写SQL），它自己就去查了

### 📌 本项目中的用法
- 大量使用 MyBatis-Plus，大部分数据库操作一行代码搞定
- 在 `mapper/` 目录下定义接口，在 `resources/mapper/` 下有 XML 文件写复杂 SQL
- 配置类：[MybatisPlusConfig.java](src/main/java/com/szy/config/MybatisPlusConfig.java)

### 📚 极简学习教程

#### 6.1 核心概念（三件套）
```
Entity（实体）  →  对应数据库的一张表
Mapper（映射器） →  操作这张表的工具
XML（映射文件）  →  写复杂 SQL 的地方（可选）
```

#### 6.2 本项目实体类示例
```java
// User.java → 对应数据库 user 表
@Data                               // Lombok 注解，自动生成 getter/setter
@TableName("sys_user")              // 指定对应的数据库表名
public class User {
    @TableId(type = IdType.AUTO)    // 主键，自增
    private Long id;
    private String username;
    private String password;
    private String realName;
    private Integer status;
}
```

#### 6.3 Mapper 接口（本项目写法）
```java
// UserMapper.java
@Mapper
public interface UserMapper extends BaseMapper<User> {
    // 继承 BaseMapper 后，下面的方法都不用写！

    // 但如果你要写复杂 SQL：
    @Select("SELECT * FROM sys_user WHERE username = #{username}")
    User findByUsername(String username);
}
```

BaseMapper 自带的方法（复制即用）：
```java
userMapper.selectById(1);              // 根据ID查询
userMapper.selectList(null);            // 查询全部
userMapper.selectOne(wrapper);          // 查询单条
userMapper.insert(user);                // 新增
userMapper.updateById(user);            // 根据ID修改
userMapper.deleteById(1);              // 根据ID删除
userMapper.selectPage(page, wrapper);   // 分页查询（项目大量使用）
```

#### 6.4 条件构造器（Wrapper）——本项目用得最多
```java
// QueryWrapper = 查询条件构造器
QueryWrapper<User> wrapper = new QueryWrapper<>();
wrapper.eq("status", 1);                  // WHERE status = 1
wrapper.like("username", "张");           // WHERE username LIKE '%张%'
wrapper.in("dept_id", list);              // WHERE dept_id IN (...)
wrapper.between("age", 20, 30);           // WHERE age BETWEEN 20 AND 30
wrapper.orderByDesc("create_time");       // ORDER BY create_time DESC

// 也可以链式写
wrapper.eq("status", 1)
       .like("username", "张")
       .orderByDesc("create_time");

// 分页查询（本项目大量使用）
Page<User> page = new Page<>(1, 10);  // 第1页，每页10条
Page<User> result = userMapper.selectPage(page, wrapper);
List<User> list = result.getRecords();  // 当前页的数据
long total = result.getTotal();         // 总记录数
```

#### 6.5 XML 写复杂 SQL（本项目用到的）
```xml
<!-- resources/mapper/UserMapper.xml -->
<mapper namespace="com.szy.mapper.UserMapper">
    <!-- 多表关联查询 -->
    <select id="getUserWithDept" resultType="com.szy.entity.User">
        SELECT u.*, d.name as deptName
        FROM sys_user u
        LEFT JOIN sys_dept d ON u.dept_id = d.id
        WHERE u.id = #{id}
    </select>
</mapper>
```

- 掌握：Entity + Mapper + BaseMapper 自带方法 + QueryWrapper

## 7. Spring Security + JWT

### 🔰 零基础定义
**Spring Security** 是**登录认证和权限管理**框架。用来判断：
1. 你是谁？（登录验证）
2. 你能做什么？（权限控制——管理员能看到所有，普通用户只能看部分）

**JWT** 是一种"通行证"机制。用户登录成功后，服务器给用户发一个加密的"字符串"（JWT令牌），之后用户每次请求都带着这个令牌，服务器就知道你是谁了。

类比：
- JWT 就像游乐园的**手环**——你去售票处（登录接口）买票，工作人员给你戴上手环（JWT令牌），之后每个项目（接口）看到你的手环就知道你有权限玩
- 手环上有加密信息（你的ID、过期时间），别人伪造不了

### 📌 本项目中的用法
- 配置在 [SecurityConfig.java](src/main/java/com/szy/config/SecurityConfig.java)
- 登录接口放行（不需要令牌就能访问），其他接口都需要令牌
- 前端每次请求在 Header 里带 `Authorization: Bearer xxx`（token）
- JWT 工具类：[JwtUtils.java](src/main/java/com/szy/util/JwtUtils.java)

### 📚 极简学习教程

#### 7.1 登录流程（本项目的完整流程）
```
① 前端发送用户名+密码 → POST /api/login
② Security 验证用户名密码是否正确
③ 正确 → 生成 JWT 令牌（包含用户ID、过期时间） → 返回给前端
④ 前端把令牌存起来（localStorage）
⑤ 之后每次请求都在 Header 带上令牌
⑥ 后端过滤器（JwtAuthenticationFilter）解析令牌，知道是谁在请求
⑦ 令牌过期 → 用户需要重新登录
```

#### 7.2 核心配置（看懂本项目这段）
```java
// SecurityConfig.java 核心代码
@Override
protected void configure(HttpSecurity http) throws Exception {
    http
        .authorizeRequests()
            .antMatchers("/api/login").permitAll()    // 登录接口不需要认证
            .antMatchers("/api/register").permitAll()  // 注册接口不需要认证
            .anyRequest().authenticated()               // 其他所有接口都需要登录
        .and()
            .sessionManagement()
            .sessionCreationPolicy(SessionCreationPolicy.STATELESS) // 无状态（用JWT，不用Session）
        .and()
            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class); // 加入JWT过滤器
}
```

#### 7.3 JWT 令牌结构（了解即可）
```
header.payload.signature
↓       ↓       ↓
(算法)  (数据)  (签名防伪造)

# 解码后看到的内容：
{
  "sub": "admin",      // 用户名
  "userId": "1",       // 用户ID
  "exp": 1700000000     // 过期时间
}
```

#### 🔗 学习建议

- 学会在浏览器 F12 → Network 中看请求 Header 里的 Authorization

## 9. Redis

### 🔰 零基础定义
Redis 是一个**存在内存中的数据库**。MySQL 的数据存在硬盘里（慢），Redis 的数据存在内存里（快）。

一般用来：
1. **缓存**：把经常查询但很少变化的数据放 Redis，减少查 MySQL 的次数
2. **临时数据**：验证码、登录状态等（丢了也没关系的数据）

类比：MySQL 是家里的**大冰箱**（储存所有食材，拿东西慢），Redis 是**灶台上的调料架**（只放常用的盐、酱油，随手就拿）。

### 📌 本项目中的用法

- 用来缓存用户登录信息、配置数据等

### 📚 极简学习教程

#### 9.1 Redis 中存什么（5种类型，但本项目只用这两种）

```
① String（字符串）     → "hello"、"token:xxx"
```

## 12. 定时任务（@Scheduled）

### 🔰 零基础定义
定时任务就是**让程序在指定时间自动执行某些操作**。比如每天凌晨2点自动备份数据，或每5分钟自动检查设备状态。

```java
    // 每5分钟执行一次
    @Scheduled(cron = "0 */5 * * * ?")
    public void syncData() {
        log.info("开始同步数据...");
        // 1. 从 collector 库读取实时数据
        // 2. 处理后写入 gcdd 库的业务表
        log.info("数据同步完成");
    }

    // 另一个定时任务：检查设备状态
    @Scheduled(cron = "0 */5 * * * ?")
    public void checkDeviceStatus() {
        // 检查设备是否离线
        // 发现离线 → 记录到故障表
    }
}
```

#### cron 表达式速查
```bash
"0 */5 * * * ?"    # 每5分钟
"0 0 2 * * ?"      # 每天凌晨2点
"0 0 8,18 * * ?"   # 每天8点和18点
"0 0/30 8-18 * * ?" # 8点到18点每30分钟
```

- 先学会看 cron 表达式就行了
- 知道 `@Scheduled` 注解加在方法上，方法就会定时执行

## 19. Axios

### 🔰 零基础定义
Axios 是**发 HTTP 请求的工具**。前端用它调用后端的接口（GET/POST/PUT/DELETE），获取数据或提交数据。

### 📌 本项目中的用法
- 配置拦截器，自动在请求头加上 JWT 令牌
- 请求地址前缀：`http://localhost:8081`

### 📚 极简学习教程
```javascript
// ① GET 请求（查询数据）
axios.get('/api/user/list', {
    params: { name: '张三', page: 1 }
}).then(res => {
    console.log(res.data);   // res.data 就是后端返回的数据
});

// ② POST 请求（新增数据）
axios.post('/api/user', {
    username: 'zhangsan',
    age: 25
});

// ③ PUT 请求（修改数据）
axios.put('/api/user', {
    id: 1,
    username: 'lisi'
});

// ④ DELETE 请求（删除数据）
axios.delete('/api/user/1');

// ⑤ 本项目中的实际用法（async/await 方式）
async getList() {
    const res = await axios.get('/api/user/list', {
        params: this.searchForm
    });
    // 后端返回的格式：{ code: 200, msg: "成功", data: [...] }
    if (res.data.code === 200) {
        this.tableData = res.data.data;
    }
}
```

#### 本项目的 Axios 拦截器（了解即可）
```javascript
// 请求拦截器：每次请求自动带上 JWT 令牌
axios.interceptors.request.use(config => {
    const token = localStorage.getItem('token');
    if (token) {
        config.headers['Authorization'] = 'Bearer ' + token;
    }
    return config;
});

// 响应拦截器：统一处理错误
axios.interceptors.response.use(res => {
    if (res.data.code === 401) {  // 未登录或令牌过期
        router.push('/login');
    }
    return res;
});
```

#### 🔗 学习建议
- 先学会 `.get()` 和 `.post()` 两个方法
- 理解 async/await 用法
- 不用深究拦截器，知道是自动加 token 的就行

## 21. ECharts（图表）

### 🔰 零基础定义
ECharts 是**图表库**，用来画折线图、柱状图、饼图、地图等数据可视化图表。

### 📌 本项目中的用法
- 页面中用来展示水质变化趋势、设备统计数据等
- 全局挂载：`Vue.prototype.$echarts = echarts`

### 📚 极简学习教程
```html
<template>
  <div ref="chart" style="width: 100%; height: 400px"></div>
</template>

<script>
export default {
  mounted() {
    this.initChart();
  },
  methods: {
    initChart() {
      const chart = this.$echarts.init(this.$refs.chart);
      chart.setOption({
        title: { text: '水质变化趋势' },
        xAxis: { data: ['周一', '周二', '周三', '周四', '周五'] },
        yAxis: {},
        series: [{
          type: 'line',    // 折线图；还可填 'bar'（柱状图）、'pie'（饼图）
          data: [120, 200, 150, 80, 70]
        }]
      });
    }
  }
}
</script>
```

#### 🔗 学习建议
- 去 [ECharts 官网](https://echarts.apache.org/zh/index.html) 看示例，复制粘贴改数据
- 重点：折线图（趋势）、柱状图（对比）、饼图（占比）

## 22. Leaflet / OpenLayers（地图/GIS）

### 🔰 零基础定义
- **Leaflet**：轻量级地图库，用来在地图上显示标记、画线、画区域
- **OpenLayers**：更专业的地图库，功能更强大
- **AMap（高德地图）**：国产地图 API

### 📌 本项目中的用法
- 在地图上标设备位置、画监测范围、显示工程分布
- 项目同时用了 Leaflet + OpenLayers + 高德地图

### 📚 极简学习教程
```html
<template>
  <div id="map" style="width: 100%; height: 500px"></div>
</template>

<script>
import L from 'leaflet';

export default {
  mounted() {
    // 创建地图
    this.map = L.map('map').setView([31.5, 113.5], 12);  // 中心点+缩放级别

    // 加载地图瓦片
    L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', {
      attribution: '© OpenStreetMap'
    }).addTo(this.map);

    // 添加标记
    L.marker([31.5, 113.5]).addTo(this.map)
      .bindPopup('设备位置');
  }
}
</script>
```

#### 🔗 学习建议
- 先学 Leaflet（更简单），会在地图上标点就行
- OpenLayers 等遇到复杂需求再学

## 23. Video.js（视频播放）

### 🔰 零基础定义
Video.js 是一个**视频播放器库**，让网页上的视频播放兼容不同浏览器，并提供统一的界面。

### 📌 本项目中的用法
- 用于播放监控摄像头视频流

```html
<template>
  <video ref="videoPlayer" class="video-js vjs-default-skin" controls>
    <source :src="videoUrl" type="application/x-mpegURL" />
  </video>
</template>

<script>
import videojs from 'video.js';

export default {
  mounted() {
    this.player = videojs(this.$refs.videoPlayer, {
      controls: true,
      autoplay: false
    });
  },
  beforeDestroy() {
    if (this.player) {
      this.player.dispose();  // 销毁播放器，防止内存泄漏
    }
  }
}
</script>
```

#### 🔗 学习建议
- 先理解概念，用到时再查具体 API

**Q：我什么都不懂，从哪开始？**
A：从第1周的 Java 基础开始，学完前4周（1个月左右）就能开始参与项目。

A：不需要！直接学 Spring Boot。本项目用的是 Spring Boot，不是原始的 Spring。

A：如果目标是全栈开发——是。如果只想做后端——Java + Spring Boot + MyBatis-Plus + MySQL 必学，前端了解即可。
